Modern ProBuilder Window for Unity 6

By Shirdhankar Technologies

Modern ProBuilder Window for Unity 6 is a lightweight editor extension designed to improve the ProBuilder workflow inside Unity 6 and above.

This tool restores quick and organized access to commonly used ProBuilder actions through a clean custom editor window, helping level designers and developers work faster without navigating through multiple Unity menus.

---

Features

Create Shapes

Quickly create commonly used ProBuilder geometry:

* Cube
* Plane
* Cylinder
* Sphere
* Stairs
* Cone

---

Selection Modes

Fast access to ProBuilder mesh editing modes:

* Vertex Mode
* Edge Mode
* Face Mode

---

Geometry Operations

Includes commonly used geometry editing tools:

* Insert Edge Loop
* Extrude Faces
* Bridge Edges
* Bevel Edges
* Fill Hole
* Flip Normals
* Detach Faces
* Merge Objects
* Collapse Vertices
* Weld Vertices

---

Object Actions

Utility tools for faster scene workflow:

* Duplicate Object
* Delete Object
* Move To Origin
* Reset Rotation
* Freeze Transform
* Random Y Rotation
* Duplicate Along X
* Duplicate Along Z

---

Grid & Snapping

* Snap Selected To Grid

---

Requirements

* Unity 6 or above
* ProBuilder package installed

---

Installation

1. Import the package into your Unity project
2. Ensure the ProBuilder package is installed via Package Manager
3. Open the tool from:

Tools → Modern ProBuilder Window

---

Notes

* This is an editor-only extension
* No runtime components are included
* Designed specifically for Unity 6 workflows
